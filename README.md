# Persona Companion Images

High-resolution visual asset pack for the [Persona Companion](https://github.com/Sentovibes/Persona-Companion-App) Android and Web application ecosystem.

## Contents & 100.0% Coverage

This repository hosts authenticated, high-resolution artwork providing complete visual coverage for all Persona games:
- **Personas (320 / 320 — 100% Coverage)**: Full artwork for all personas across Persona 3 (FES, Portable, Reload, Episode Aigis), Persona 4 (Vanilla, Golden), and Persona 5 (Vanilla, Royal).
- **Enemies & Bosses (642 Sprites / 874 Catalog Entries — 100% Coverage)**: Full artwork coverage for all story bosses, Tartarus floor guardians, Colosseo Purgatorio encounters, Monad Passages, Palace rulers, Mementos targets, and superbosses (including Metis, Shadow Protagonist, Akihiko, Ken, Junpei, Koromaru, Yukari, Mitsuru, Joker, Shadow Rise, Jose, Caroline & Justine, Cognitive Haru's Fiance, Goro Akechi, Dr. Takuto Maruki, Yaldabaoth, and Holy Grail).

## Usage

- **Automatic In-App Sync**: The Persona Companion Android application automatically checks, downloads, and validates `images.zip` upon initial setup or update.
- **Manual Import**: Download `images.zip` and import it directly into the Android app via **Settings -> Images -> Import images.zip**.
